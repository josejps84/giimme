# Giimme

Página de descargas de Giimme: https://giimme.josepineros.dev (GitHub Pages).

El APK se publica como asset `giimme.apk` de un GitHub Release con
`scripts/release-apk.sh` del repo privado `gym-app`. La página enlaza a
`releases/latest/download/giimme.apk`, así que siempre apunta a la última versión.
